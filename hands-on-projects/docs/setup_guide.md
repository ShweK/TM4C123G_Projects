# Development Environment Setup for TM4C123G Projects

## 🔧 Requirements

- TM4C123GXL LaunchPad
- Code Composer Studio (TI)
- TivaWare driver library
- Optional: arm-none-eabi-gcc toolchain for Makefile builds

## 📦 Install Code Composer Studio

1. Download CCS: https://www.ti.com/tool/CCSTUDIO
2. During installation, select "Tiva C Series Support"
3. Plug in the board and create a new project in CCS using the TM4C123GH6PM device.

## ⚙️ Flashing the Board

Use CCS Debugger or LM Flash Programmer for standalone flashing:
- LM Flash Programmer: https://www.ti.com/tool/LMFLASHPROGRAMMER
